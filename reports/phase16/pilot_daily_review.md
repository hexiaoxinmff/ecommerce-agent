# Phase 16 Pilot 每日轻量复盘（pilot_daily_review）

> 收工前 5 分钟由陪跑人员填写，一天一节；只做计数与模式观察，不做修复决策。
> 特别关注：**同一种问题是否重复出现**——一次问题不一定值得改，连续出现 ≥3 次才进入候选产品问题。

## 模板（每日复制一节填写）

```markdown
### YYYY-MM-DD（第 __ 天 / 10）

- 今日问题数量：
- 成功：
- 技术失败（technical）：
- 业务错误（business_semantic）：
- 概念不存在（concept_not_exists / Unsupported Concept）：
- 模糊问题（user_intent_ambiguity / Ambiguous Time）：
- 用户主动重复提问（同一问题再问）：
- 用户放弃（问了没等结果 / 换走）：
- 今日备注（重复出现的模式、用户情绪、已登记的 Issue ID）：
```

## 中期检查点（第 5 个工作日填写）

- 是否触发暂停线（F1~F4）：无 / 有（哪一条）：
- 目前已重复 ≥2 次的问题：
- 用户是否已出现自发非测试问题：YES / NO
- 使用是否出现衰减迹象：YES / NO
- 小修复执行记录（如有，须与 pilot_issue_log.md 对应）：

## 期末检查（第 10 个工作日填写）

- 第 2 周使用天数 vs 第 1 周：
- 高频失败问题（连续 ≥3 次）清单及对应 Issue ID：
- 用户自评（5 分制，试点期末）：
- 移交总结报告：`第十六阶段_Business_Pilot试点总结报告.md` 已按真实数字填写
